# Development of Intrusion Detection System Using Snort

This repository contains a simple, responsive website for the IDS project with:

- A combined login and registration page (`index.html`)
- A "next step" implementation roadmap page (`next-step.html`)

## Open the Website

### Option 1: Directly open the HTML file
Open this file in your browser:

```
/tmp/workspace/aviralkumar09/IDS-using-Snort/index.html
```

### Option 2: Run a local web server (recommended)
From the repository root, run:

```
python -m http.server 8000
```

Then open:

```
http://localhost:8000/index.html
```
